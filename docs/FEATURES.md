# Completed-feature register and screen inventory

Release 0.1.0, 29 October 2026; Phase 1 commercial core (V3–V9) and Phase 2 advanced factory operations (V10–V15, integrated by V16), November 2026; Phase 3 security starts with two-step sign-in (V17); Phase 4 finance core starts with taxes (V25). Scope: foundation, reconciled manufacturing lifecycle, commercial core and advanced factory operations. Modules are **partial** unless all requirements from the master brief are delivered. The UI never promotes a future capability as a working module.
